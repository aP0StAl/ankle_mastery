# Ankle Mastery

Личное приложение для восстановления голеностопа: что сделать сейчас, сколько уже выполнено и как меняется подготовка к бегу. Программа учитывает текущую травму и назначения владельца.

## Запуск

Откройте `index.html` в браузере. Установка, сервер и сборка не нужны. Для переноса приложения копируйте `index.html` вместе с папками `src/`, `styles/` и `assets/`. Подходит и обычный статический хостинг.

Записи сохраняются в `localStorage` текущего браузера. Перед сменой браузера, устройства или адреса приложения используйте экспорт JSON во вкладке «Настройки», затем импортируйте копию на новом месте. Личные копии в `.local-backups/` исключены из Git.

Ответы о самочувствии и параметры упражнений намеренно переиспользуются. Владелец сообщает изменения сам; повторно подтверждать неизменившиеся ответы не нужно. Правила разработки — в [AGENTS.md](AGENTS.md).

## Где что находится

| Путь | Содержимое |
|---|---|
| `index.html` | Разметка экранов и порядок подключения скриптов |
| `styles/app.css` | Оформление и мобильная раскладка |
| `src/config/` | Настройки программы, каталог упражнений и протоколы измерений |
| `src/core.js` | Хранение, миграция, импорт/экспорт, журнал решений и общие функции |
| `src/recovery.js` | Симптомы, отложенная реакция и подтверждение переносимости |
| `src/progression.js` | Рабочая доза, возврат после облегчения и очередь повышений |
| `src/planner.js` | Состав, остаток и завершение дополнительного занятия |
| `src/load.js` | Запись упражнений и учёт общей нагрузки |
| `src/measurements.js` | Результаты, сессии и доступность измерений |
| `src/recommendations.js` | Домашний план, выбор следующего действия и отсрочки |
| `src/progress.js` | Цели, прогресс и условия перехода между этапами |
| `src/running.js` | Беговой план, пробежки и их подтверждение |
| `src/ui/` | Экраны, карточки и формы ввода |
| `src/app.js` | Загрузка сохранений, обработчики и первый показ экранов |
| `assets/exercises/` | Изображения и исходные промпты для них |
| `tests/` | Проверки правил и мобильных сценариев |
| `docs/` | Описание приложения, обоснования программы и исследования |

Скрипты обычные, без `import` и сетевой загрузки данных: так сохраняется запуск через `file://`. Они разделяют область имён приложения и подключаются последовательно. Настройки загружаются первыми; `src/app.js` запускается последним, когда все функции уже определены. Вызовы из разметки используют `window.AM`. При добавлении исходного файла подключите его в `index.html`: тесты читают тот же список и выполняют файлы в том же порядке.

## Проверка

```sh
node --test tests/app.test.cjs
```

Node нужен только для разработки. Проверки охватывают сохранения, рекомендации, дозы, восстановление, конечность занятий, измерения и переходы.

Мобильные сценарии используют отдельные синтетические сохранения, проверяют формы и перезагрузку и сохраняют снимки в `/tmp/ankle-mobile-qa`:

```sh
node tests/mobile-scenarios.cjs
```

Для них нужен установленный Playwright и Chrome. Если Playwright находится вне проекта, укажите его каталог через `NODE_PATH`; путь к Chrome при необходимости задаётся через `CHROME_PATH`. Скриншоты и личные резервные копии в репозиторий не добавляются.
